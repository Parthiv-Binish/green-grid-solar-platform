# Installation and Project Management

## 1. Project creation

Create a project from an accepted quotation and agreement. Snapshot the accepted system BOM and commercial terms so later catalogue or price changes do not alter the project record.

## 2. Suggested stages

1. Awaiting agreement / initial payment.
2. Technical design finalisation.
3. Utility / scheme documentation preparation (where applicable).
4. Procurement.
5. Materials received.
6. Installation scheduled.
7. Mounting and module installation.
8. Inverter / battery / electrical work.
9. Testing and commissioning.
10. Inspection / utility process (where applicable).
11. Handover.
12. Completed.
13. On hold / cancelled.

Actual stages should be configured to match Green Grid's operating process and current scheme / utility rules.

## 3. Project record

- Project number.
- Customer and property.
- Accepted quotation version.
- System configuration and BOM.
- Project owner and assigned team.
- Planned and actual dates.
- Milestones and dependencies.
- Procurement and material allocation.
- Site notes and risks.
- Photos and evidence.
- Test / commissioning records.
- Customer approvals.
- Utility / scheme reference details where applicable.
- Handover checklist and documents.

## 4. Staff workflow

Project lead assigns tasks and dates. Technicians update only their assigned work. Technical sign-off is restricted to authorised roles. Delays and blockers must have a reason, owner and next action.

## 5. Handover checklist

- Installed equipment list and serial numbers.
- System configuration and approved design.
- Commissioning / test records.
- Safety and operating instructions.
- Monitoring setup instructions, if available.
- Warranty documents and registration status.
- Customer training acknowledgement.
- Support contact and escalation route.
- Outstanding work, if any.

## 6. Customer progress view

Show customer-friendly milestone labels and dates. Do not expose internal notes, supplier costs, staff private data or security-sensitive site details.
