## Navigation principles

- Public navigation should prioritise Solutions, Products, Calculator, Projects and Contact.
- Primary CTA: “Request a Site Assessment”.
- Customer login should be visible but not dominate the public experience.
- Staff routes must be protected and excluded from public navigation and indexing.
- Breadcrumbs should be used on deeper product, solution and project pages.
- Footer should contain verified contact information, service links, policies and social links only when maintained.
