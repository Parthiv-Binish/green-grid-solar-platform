# Visual asset usage and quality policy

## Asset classes
1. **Owned** — supplied by Green Grid or created under its ownership; retain source/editable masters.
2. **Licensed** — third-party stock/brand assets with a documented licence or permission.
3. **Generated illustrative** — AI-generated scene used as generic illustration, never project evidence.
4. **Reference only** — external logo/source link not copied into the repository.
5. **Pending** — required but no verified source or approval yet.

## Required metadata
Each image should have: descriptive filename, asset class, source/creator, licence/permission, download or creation date, intended placement, alt text, dimensions, and approval state.

## Image rules
- No text baked into photos; page text remains accessible and editable.
- No logos, watermarks, fabricated badges, certification marks, uniforms or signage in generated scenes.
- No invented customer/project identities, installation capacity, savings, subsidy or warranty claims.
- Generated solar installations must be labelled illustrative in repository metadata.
- Use real project images only with customer/site consent and accurate project details.
- Crop with subject-safe areas; provide mobile and desktop variants when composition requires it.
- Compress responsibly; retain a high-quality source master.

## Logo rules
- Never redraw or approximate an official logo.
- Never recolour, distort, crop, animate or combine marks unless the official brand guide allows it.
- Maintain clear space and minimum size.
- Do not put government/utility logos in a "trusted by", "approved by", "certified by" or partner strip without documentary proof and permission.
- Do not imply product brands are Green Grid partners simply because their products are listed.

## Accessibility
- Meaningful images need concise descriptive alt text.
- Decorative images use empty alt text in the UI.
- Icons with actions require visible text labels or accessible names.
- Maintain WCAG contrast; don't communicate status by colour alone.
- Avoid text embedded in images and respect reduced-motion preferences.
