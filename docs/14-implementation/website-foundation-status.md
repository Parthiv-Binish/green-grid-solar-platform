# Website foundation — implementation status

## Implemented in the first React JavaScript pass
- Vite + React application entry point and router.
- Public site shell with responsive navigation and footer.
- Home, Solutions, About, Contact and 404 routes.
- Initial design tokens, responsive SCSS and reduced-motion handling.
- Accessible skip link, semantic sections, labels and inline enquiry validation.
- On-grid/off-grid/hybrid plain-language explanation.
- Enquiry form explicitly does not claim submission success while backend is unconfigured.
- Initial illustrative solar-system SVG diagrams.

## Not yet implemented / integration blockers
- Generated photo masters need binary optimisation and upload into `public/assets/images`.
- Official Green Grid logo and brand palette approval.
- Real business contact details, service areas, registration and policy/legal copy.
- CMS-backed page content and product catalogue.
- Supabase project URL/anon key and Edge Function deployment.
- Enquiry persistence, email notification and consent retention.
- Customer portal, staff workspace and admin console.
- Full accessibility, browser and device QA; CI and deployment configuration.

## Important data rule
No fabricated project records, testimonials, ratings, customer names, product catalogue, pricing, savings, certifications, staff identities or government endorsements are included.
