# Customer Journeys

## Journey 1 — First-time residential customer

1. Lands on homepage from search, referral or advertisement.
2. Selects “Calculate solar savings” or “Explore home solar”.
3. Reads on-grid / hybrid explanation.
4. Enters approximate bill, location and usage information.
5. Reviews indicative result and assumptions.
6. Requests a site assessment.
7. Receives enquiry reference and confirmation.
8. Sales staff qualifies request.
9. Appointment is proposed and confirmed.
10. Surveyor completes site inspection.
11. Customer receives itemised proposal.
12. Customer requests revision or accepts a version.
13. Agreement and payment schedule are recorded.
14. Customer tracks project and receives updates.
15. Customer receives handover and warranty documents.
16. Customer can raise a support request later.

## Journey 2 — Backup-focused customer

The customer selects “I need backup during power cuts”. The experience must not recommend a basic on-grid system as if it provides backup. Ask which loads are essential, approximate load wattage and desired backup duration. A qualified technical person must validate the battery and inverter design.

## Journey 3 — Commercial enquiry

Collect organisation / contact details, site address, property type, electricity bill(s), operating hours, available roof / land information and project objective. Route to commercial sales / technical review. Do not force a residential package or simple calculator result.

## Journey 4 — Existing customer support

1. Customer signs in or verifies identity.
2. Selects installed system / product.
3. Chooses issue category.
4. Describes issue and uploads optional evidence.
5. Receives ticket reference.
6. Support triages urgency and safety.
7. Ticket is assigned and status updates are sent.
8. Service visit is scheduled if needed.
9. Resolution and service report are recorded.
10. Customer can provide feedback.

## Journey 5 — Staff lead-to-installation

Lead created → assigned → contacted → qualified → survey scheduled → survey completed → technical review → quotation drafted → approved → sent → revised / accepted / declined → project created → procurement → installation scheduling → installation → testing / commissioning → handover → support.

## UX rules

- Do not make account creation mandatory before a basic enquiry.
- Explain why each sensitive document is requested.
- Save progress where practical.
- Make appointment status explicit: requested, pending confirmation, confirmed, rescheduled, cancelled, completed, no-show.
- Use plain language and explain technical terms.
- Provide a human contact route at important decision points.
