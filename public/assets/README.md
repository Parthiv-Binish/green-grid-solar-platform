# Green Grid visual asset library

This directory contains approved brand files, original visual assets, licensed third-party assets, and source/usage records.

## Rules
- Do not fabricate Green Grid branding, project evidence, customer testimonials, product specifications, certifications, government endorsements, or partner relationships.
- Use only approved Green Grid logo masters supplied by the business.
- Third-party government and manufacturer logos are references only until their usage terms and permissions are confirmed.
- Every image must have an asset record with source, licence/permission, intended use, alt text, and review status.
- Generated photographs are illustrative, not evidence of completed Green Grid installations.
- Prefer SVG for logos/icons, WebP/AVIF for web photography, and PNG only where transparency is needed.

See [asset inventory](./ASSET-INVENTORY.md), [official logo and asset sources](./OFFICIAL-LOGO-ASSET-SOURCES.md), and [usage policy](./USAGE-POLICY.md).
